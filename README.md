The following source code will help you build a very beautiful javafx application that manages the claims raised/submitted by the employees working in a company named: Chai.Co.
This application accepts the username and emailID of the employee and then allows you to input all the details such as category of the expense, amount, description and a picture/pdf of proof.
After the claim has been submitted, the employee will receive a mail on the given mail ID, which had been entered during the login. 
The Finance team can also login, and then view the dashboard which after refreshing shows all the pending claims.
The finance team can then aproove it/reject it and accordingly a status update mail will be sent to the employee on the same mail ID.
For managing the database, we have used : PostresSQL in PGAdmin.
