The following source code will help you build a very beautiful JavaFX application that manages the claims raised/submitted by employees at Chai.co. This application accepts the employee's username and email ID and allows you to enter the expense category, amount, description, and a picture/pdf of proof. After the claim has been submitted, the employee will receive an email on the given mail ID, which had been entered during the login. The Finance team can also login, view the dashboard, which after refreshing shows all the pending claims. The finance team approves/rejects it, and accordingly, a status update email will be sent to the employee. For managing the database, we have used PostgreSQL in PGAdmin. Thank you so much.
